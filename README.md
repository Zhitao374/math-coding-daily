# math-coding-daily

> 用数学引入编程思维 · 每日一题 · C++ 零基础到算法进阶

一套面向大众（学生、家长、非程序员）的编程学习内容系统。每天一张海报，用最小的数学例子讲清一个算法思维转身，覆盖从零基础到 CSP-J/S 竞赛的完整路径。

---

## 项目简介

**这不是一套"教程"，而是一套"每日一题"的知识海报系统。**

每道题包含：

- **题目场景** —— 一句话说清要解决什么
- **思考方式** —— 从"朴素想法"到"关键突破"的三台阶
- **关键代码** —— 6-15 行核心逻辑
- **知识扩展** —— 数学关联、编程思维、延伸思考
- **分享文案** —— 一键复制，直接发朋友圈

海报以**单页 HTML** 形式呈现，支持：

- 目录页搜索、筛选、加载更多
- 键盘 `←` `→` 翻页
- 一键导出 PNG（朋友圈长图）
- 一键复制分享文案

## 核心特性

| 特性 | 说明 |
|---|---|
| **内容即数据** | 每道题一个 `.md` 文件，front-matter 存元数据，正文写内容 |
| **一次构建** | `npm run build` 把 46 个 `.md` 打包成单个 `dist/index.html` |
| **纯前端** | 双击 `dist/index.html` 即可浏览，无需服务器 |
| **一键导出** | 点击"下载 PNG"导出海报长图，直接发朋友圈 |
| **一键复制** | 点击"📋 文案"复制分享文案 |
| **键盘翻页** | `←` `→` 翻题，`Esc` 回目录 |
| **目录筛选** | 按阶段筛选、按关键词搜索 |
| **8 套主题色** | 按知识阶段自动切换配色 |

## 快速开始

### 环境要求

- Node.js 18+
- Windows / macOS / Linux 均可

### 安装

```bash
git clone https://github.com/Zhitao374/math-coding-daily.git
cd math-coding-daily
npm install
```

### 构建

```bash
npm run build
```

**期望输出**：

```
构建完成：46 篇内容 → dist/index.html (0.XX MB)
```

### 浏览

双击 `dist/index.html`，浏览器打开。

**强制刷新**（如果更新过内容）：`Ctrl + Shift + R`

```
math-coding-daily/
├── content/                    # 内容源文件（你写这个）
│   └── 01-语法筑基/
│       ├── 001-A+B 问题.md
│       ├── 002-输出字符三角形.md
│       └── ...
├── templates/                  # 模板（一次配好，基本不动）
│   ├── index.html              # 页面骨架
│   ├── app.js                  # 前端路由 + 渲染
│   └── styles/
│       ├── 01-reset.css
│       ├── 02-themes.css       # 8 套主题色
│       ├── 03-index.css        # 目录页
│       ├── 04-poster.css       # 海报本体
│       └── 05-ui.css           # 工具栏
├── docs/                       # 项目文档
│   ├── 内容设计规范.md
│   ├── 朋友圈文案设计规范.md
│   ├── 选题总规划.md
│   ├── 第一年详细排期.md
│   ├── 第二年详细排期.md
│   └── 第三年详细排期.md
├── build.js                    # 构建脚本
├── package.json
└── dist/                       # 构建产物（自动生成，不手改）
    └── index.html
```

**关键原则**：

- **你只写 `content/` 下的 `.md`**
- `templates/` 和 `build.js` 一次配好，基本不动
- `dist/` 随时可以删掉重建

## 如何新增一题

### 第 1 步：新建 `.md` 文件

在 `content/01-语法筑基/` 下新建：

```
046-新的题目.md
```

**文件名规则**：三位数编号 + 连字符 + 中文标题

### 第 2 步：写 front-matter

```yaml
---
day: 046
title: 新的题目
subtitle: 一句话点出核心
stage: 编程基础
theme: warm
platform: 洛谷
problem_id: P1234
url: https://www.luogu.com.cn/problem/P1234
tags: [标签1, 标签2, 标签3]
fore: 下期预告
share: |
  钩子文案第一行。
  钩子文案第二行。

  #数学思维 #编程思维 #每日一题
---
```

### 第 3 步：写正文

```markdown
## 题目

（场景 + 输入输出格式 + 数据范围）

## 输入输出样例

| 输入 | 输出 |
|---|---|
| ... | ... |

## 思考方式

### 朴素想法

（读者第一反应会怎么做）

### 发现规律

（从具体例子观察规律）

### 关键突破

（从观察中提炼新思路）

## 代码

```cpp
// 6-15 行核心代码
```

## 知识扩展

- **数学关联**：……
- **编程思维**：……
- **延伸思考**：……
```

### 第 4 步：构建

```bash
npm run build
```

### 第 5 步：验证

刷新浏览器，新题应该出现在目录里。

## 技术栈

| 层 | 技术 |
|---|---|
| **内容** | Markdown + YAML front-matter |
| **解析** | [markdown-it](https://github.com/markdown-it/markdown-it) + [gray-matter](https://github.com/jonschlinkert/gray-matter) |
| **构建** | Node.js 脚本 |
| **前端** | 原生 HTML / CSS / JavaScript（无框架） |
| **代码高亮** | [highlight.js](https://highlightjs.org/) |
| **图片导出** | [html2canvas](https://html2canvas.hertzen.com/) |

**为什么不用框架？**

- 单页应用 + 静态数据，不需要 React/Vue
- 双击 HTML 就能用，不依赖服务器
- 依赖少，长期维护成本低

## 常见问题

### Q: 为什么内容用 `.md` 而不是 YAML？

A: Markdown 更适合写正文（题目、思考过程、代码），YAML 只用来存元数据（front-matter）。两者结合，写作体验和机器解析两不误。

### Q: 为什么不是每个题一个 HTML？

A: 单文件 HTML 便于分享——把 `index.html` 发给别人，双击就能看全部。多文件 HTML 分享时要打包整个文件夹。

### Q: 为什么导出 PNG 而不是 PDF？

A: 朋友圈发的是图片。PNG 长图直接能发，PDF 要转图片。

### Q: 内容会超过浏览器承载能力吗？

A: 46 题约 0.08 MB。300 题约 0.5 MB，1000 题约 2 MB。**1000 题以内不会有明显性能问题**。超过时再优化（目录分页已有预案）。

### Q: 可以用英文/其它语言写内容吗？

A: 可以。`build.js` 不限制语言，字体栈已包含常见中文字体。
