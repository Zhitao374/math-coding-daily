## 题目

小玉有 a 元 1 角，铅笔 b 元 1 角一支。她最多能买多少支？

输入：a b（小玉的钱数（元）、铅笔单价（元））
输出：一个整数（最多能买几支）

数据范围：0 ≤ a, b ≤ 100。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 10 3 | 2 |

## 思考方式

### 朴素想法

"最多买几支"就是做除法。
但 10 元 1 角 = 101 角，3 元 1 角 = 31 角。

101 ÷ 31 = 3.258……，所以能买 3 支。

答案就是"商的整数部分"。

### 发现规律

C++ 里，两个整数相除时，
结果会自动**向下取整**，只保留整数部分。

```
101 / 31 = 3   （不是 3.258）
```

这和数学里的除法不一样，
但正好符合"能买几支"的需求。

关键洞察：**单位要先统一**。元转成角，
小数运算就变成整数运算。

### 关键突破

整数除法 vs 小数除法，由数据类型决定：

- `int / int` → 整数除法，结果取整
- `double / int` → 浮点除法，保留小数

想得到"最多能买几支"，先把单位统一，
再用整数除法。

## 代码

```cpp
int a, b;
cin >> a >> b;
int total = a * 10 + 1;      // "a 元 1 角"换算成角：a×10+1
int price = b * 10 + 1;      // "b 元 1 角"换算成角
cout << total / price;       // 整数除法自动取整
```

## 知识扩展

- **数学关联**：整除与带余除法的区别
- **编程思维**：数据类型决定运算结果，整数除法向下取整是 C++ 的默认行为
- **延伸思考**：如果想算"剩下多少钱"，应该用哪个运算？
