## 题目

小明和小红各有一个数字。把这两个数加起来，输出结果。

输入：a b（两个整数）
输出：一个整数（a + b）

数据范围：-10^9 ≤ a, b ≤ 10^9。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 20 30 | 50 |

## 思考方式

### 朴素想法

数学上，3 + 5 = 8，心算就知道。
但计算机只会机械地执行指令——
它不知道"3"和"5"从哪里来，
也不知道"8"要送到哪里去。

要让计算机做加法，得先告诉它三件事：
数从哪来？做什么运算？结果放哪？

### 发现规律

计算机做任何事都是同样的三步：

第一步：读入数据（从哪里拿）
第二步：处理数据（做什么运算）
第三步：输出结果（放回哪里）

A+B 就是最简单的三步走。

### 关键突破

把这三步翻译成 C++ 只需要三行：

```
int a, b;          // 第一步：准备两个盒子
cin >> a >> b;     // 第二步：把数放进去
cout << a + b;     // 第三步：算出结果并输出
```

所有程序，本质上都是这三步的扩展。

## 代码

```cpp
int a, b;
cin >> a >> b;
cout << a + b;
```

## 知识扩展

- **数学关联**：加法满足交换律，a + b 与 b + a 结果相同
- **编程思维**：程序 = 输入 + 处理 + 输出，这是所有程序的骨架
- **延伸思考**：如果两个数加起来超过了 int 的范围（约 21 亿），会发生什么？
