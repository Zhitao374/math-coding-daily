## 题目

统计 [L, R] 范围内所有整数中，数字 2 出现的总次数。

比如 1 到 22 之间：数字 2 出现在
2、12、20、21、22——一共 6 次（22 里有两个 2）。

输入：两个整数 L R
输出：一个整数（数字 2 出现的总次数）

数据范围：1 ≤ L ≤ R ≤ 100000。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 2 22 | 6 |

## 思考方式

### 朴素想法

"统计数字 2 出现了几次"——
最直接的方法是把每个数当作字符串，逐位扫描。

但更常见的方式是用数学方法：
**把一个数逐位拆开**——怎么拆？

### 发现规律

每个整数都可以通过"取余 + 整除"来拆位：

```
123 的个位 = 123 % 10 = 3
去掉个位   = 123 / 10 = 12
12 的个位  = 12 % 10 = 2
去掉个位   = 12 / 10 = 1
1 的个位   = 1 % 10 = 1
```

对每个数，循环"取余 → 判断 → 除以 10"，
直到数为 0。

### 关键突破

循环结构是**双层嵌套**：

- **外层**：遍历 L 到 R 的每个数
- **内层**：拆解当前数的每一位

```
for (int i = L; i <= R; i++) {
    int x = i;
    while (x > 0) {
        if (x % 10 == 2) cnt++;
        x /= 10;
    }
}
```

这里 `while (x > 0)` 是关键——
只要还有位没拆完，就继续。

## 代码

```cpp
int L, R;
cin >> L >> R;
int cnt = 0;
for (int i = L; i <= R; i++) {
    int x = i;
    while (x > 0) {
        if (x % 10 == 2) cnt++;
        x /= 10;               // 去掉个位
    }
}
cout << cnt;
```

## 知识扩展

- **数学关联**：位值原理——数字在不同位置代表不同权重
- **编程思维**：嵌套循环——外层遍历、内层处理，是处理"二维问题"的标准结构
- **延伸思考**：如果改成"统计数字 2 和 3 出现的总次数"，内层要改几处？
