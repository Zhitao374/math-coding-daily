## 题目

给 n 个数，求它们的总和与平均值。

输入：第一行一个整数 n；第二行 n 个整数
输出：两个数（总和、平均值，平均值保留两位小数）

数据范围：1 ≤ n ≤ 100，每个数不超过 1000。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 5<br>3 7 2 9 5 | 26 5.20 |

## 追踪

| i | a[i] | sum |
|---|---|---|
| 0 | 3 | 3 |
| 1 | 7 | 10 |
| 2 | 2 | 12 |
| 3 | 9 | 21 |
| 4 | 5 | 26 |

## 思考方式

### 朴素想法

求和就是"累加"——和之前做过的一样：

```
sum = 0;
for (int i = 0; i < n; i++) {
    sum += a[i];
}
```

平均值就是 `sum / n`。

看起来简单——但最后输出时有个坑。

### 发现规律

坑在**平均值的数据类型**：

- 如果 `sum` 是 `int`，`n` 是 `int`，那 `sum / n` 是**整数除法**——会丢小数
- 26 / 5 = 5，不是 5.2

必须让除法变成**浮点除法**。

### 关键突破

两种写法都行：

**写法 A**：把 `sum` 定义成 `double`

```
double sum = 0;
```

**写法 B**：除法时强制转换

```
cout << (double)sum / n;
```

**写法 B 更常用**——`sum` 用 int 累加更快更准，最后再做浮点除法。

## 代码

```cpp
int n;
cin >> n;
int a[105];
for (int i = 0; i < n; i++) cin >> a[i];

int sum = 0;
for (int i = 0; i < n; i++) {
    sum += a[i];
}

cout << sum << " ";
cout << fixed << setprecision(2) << (double)sum / n;
```

## 知识扩展

- **数学关联**：总和是"累积量"，平均值是"归一化后的累积量"
- **编程思维**：整数除法会截断——涉及小数时，必须做类型转换
- **延伸思考**：如果要算"去掉最高分和最低分后的平均值"，程序要改哪几步？
