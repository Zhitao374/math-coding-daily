## 题目

P 老师要买 n 支铅笔作为奖品。商店有 3 种包装，每种包装的支数和价格都不同。

**求最少花多少钱。**

约束：

- 只买同一种包装
- 包装不允许拆开
- 每种包装的库存都足够

输入：第一行一个整数 n；后三行每行两个整数（每包支数 每包价格）
输出：一个整数（最少花费）

数据范围：1 ≤ n ≤ 10000，1 ≤ 每包支数、每包价格 ≤ 10000。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 57<br>2 2<br>50 30<br>30 27 | 54 |

## 对比

| 只看单价 | 算整包总价 |
|---|---|
| 2 支装：1.0 元/支 | 29 包 → 58 元 |
| 50 支装：0.6 元/支 | 2 包 → 60 元 |
| 30 支装：0.9 元/支 | 2 包 → 54 元 |
| 单价最低 ≠ 总价最低 | 三种包装各算一遍取最小 |

## 思考方式

### 朴素想法

要求"只买一种包装"——所以只有 3 种买法，每种算法都一样。三种买法各算一遍：

- 只买 2 支装：57 ÷ 2 = 28.5，向上取整 → 29 包，29 × 2 = **58 元**
- 只买 50 支装：57 ÷ 50 = 1.14，向上取整 → 2 包，2 × 30 = **60 元**
- 只买 30 支装：57 ÷ 30 = 1.9，向上取整 → 2 包，2 × 27 = **54 元**

三种里挑最小的：**54 元**。

### 发现规律

注意：50 支装的单价是 0.6 元/支（30 ÷ 50），是三种里最便宜的。

但算总价，50 支装反而最贵——
因为 57 支要买 50 支装的话，1 包不够，得买 2 包，
多买了 43 支没用的铅笔。

**不能只看单价，要算"整包买"的总价。**

### 关键突破

对每种包装，计算需要几包，再乘以单价：

```
包数 = 向上取整(n ÷ 每包支数)
     = (n + 每包支数 - 1) / 每包支数
总价 = 包数 × 每包价格
```

三种包装各算一遍，取最小。

这就是"枚举"思想——不猜哪种最便宜，而是把三种都算一遍，取最优。

## 代码

```cpp
int n;
cin >> n;
int ans = 1e9;                         // 初始值：设得很大
for (int i = 0; i < 3; i++) {
    int num, price;
    cin >> num >> price;
    int packs = (n + num - 1) / num;   // 向上取整
    int cost = packs * price;
    if (cost < ans) ans = cost;        // 取最小值
}
cout << ans;
```

## 知识扩展

- **数学关联**：向上取整——"够不够"类问题的常用技巧
- **编程思维**：枚举所有可能取最优，是贪心算法的雏形
- **延伸思考**：如果允许"混着买"（三种包装各买一些），答案会变吗？
