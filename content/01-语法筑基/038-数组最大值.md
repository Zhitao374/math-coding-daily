## 题目

给 n 个数，找出其中最大的那个，并输出它是第几个数（从 1 开始编号）。

输入：第一行一个整数 n；第二行 n 个整数
输出：两个整数（最大值、最大值的第一个出现位置）

数据范围：1 ≤ n ≤ 100，每个数不超过 10000。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 5<br>3 7 2 9 5 | 9 4 |

## 追踪

| 下标 i | a[i] | maxVal | pos |
|---|---|---|---|
| 0 | 3 | 3 | 1 |
| 1 | 7 | 7 | 2 |
| 2 | 2 | 7 | 2 |
| 3 | 9 | 9 | 4 |
| 4 | 5 | 9 | 4 |

## 思考方式

### 朴素想法

如果不在数组上做，可以一边读一边比较：

```
int maxVal = a[0];
for (int i = 1; i < n; i++) {
    if (a[i] > maxVal) maxVal = a[i];
}
```

能求出最大值——但如果要求"**位置**"呢？
刚读过的数就忘了，没法回去数它是第几个。

还有一个隐患：如果 `maxVal` 设成 0，而数据里有负数，
最大值会错。用 `a[0]` 做初值才稳妥。

### 发现规律

用数组**先把所有数存起来**，然后：

- 用变量 `maxVal` 记录当前最大值（初值 `a[0]`）
- 用变量 `pos` 记录最大值的位置（初值 `1`）

循环遍历：

```
int maxVal = a[0];
int pos = 1;
for (int i = 1; i < n; i++) {
    if (a[i] > maxVal) {
        maxVal = a[i];        // 更新最大值
        pos = i + 1;          // 更新位置（下标转位置）
    }
}
```

**每次发现更大的数，就同时更新两个变量。**

### 关键突破

注意两个细节：

**细节 1**：位置从 1 开始编号，但数组下标从 0 开始——
所以 `pos = i + 1`。

**细节 2**：如果**最大值有多个**，题目要求"第一个出现位置"——
所以用 `>`，不用 `>=`。这样只有严格更大才更新，第一个最大值会保持不变。

## 代码

```cpp
int n;
cin >> n;
int a[105];
for (int i = 0; i < n; i++) cin >> a[i];

int maxVal = a[0];               // 先假设第一个数最大
int pos = 1;                     // 位置从 1 开始
for (int i = 1; i < n; i++) {
    if (a[i] > maxVal) {         // 严格大于才更新
        maxVal = a[i];
        pos = i + 1;
    }
}
cout << maxVal << " " << pos;
```

## 知识扩展

- **数学关联**：极值 = 最大值 / 最小值，`max` 和 `min` 是集合的两个基本性质
- **编程思维**：`>` 和 `>=` 的区别——处理"重复极值"时非常关键
