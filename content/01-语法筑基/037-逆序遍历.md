## 题目

给一列数（以 0 结束），逆序输出它们（不包括 0）。

输入：一行若干整数，以 0 结束
输出：逆序后的整数，空格分隔

数据范围：输入不超过 100 个数，每个数不超过 1000。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 3 1 4 1 5 9 0 | 9 5 1 4 1 3 |

## 追踪

| i | a[i] | 状态 |
|---|---|---|
| 0 | 3 | 读入 |
| 1 | 1 | 读入 |
| 2 | 4 | 读入 |
| 3 | 1 | 读入 |
| 4 | 5 | 读入 |
| 5 | 9 | 读入 |
| — | — | 遇到 0，停止 |

## 思考方式

### 朴素想法

读入一行数，遇到 0 停止。
然后**倒着输出**——从最后一个数往前，一直输出到第一个。

问题：读的时候是"从前往后"，输出要"从后往前"。
怎么记得"最后一个数是哪个"？

### 发现规律

用数组下标追踪——**读入时用变量 `cnt` 记录读了多少个数**：

```
int cnt = 0;
while (cin >> x && x != 0) {
    a[cnt] = x;
    cnt++;                 // 计数加一
}
```

读完后，`cnt` 就是数组的有效长度。

**逆序输出**就是从下标 `cnt - 1` 走到 `0`：

```
for (int i = cnt - 1; i >= 0; i--) {
    cout << a[i] << " ";
}
```

### 关键突破

**关键观察**：数组可以"正着存，倒着取"。
存的时候从 `0` 到 `cnt-1`，取的时候从 `cnt-1` 到 `0`。

倒着遍历的循环：

```
for (int i = cnt - 1; i >= 0; i--)
```

**下标从大到小**，就实现了逆序。

## 代码

```cpp
int a[105];
int cnt = 0;
int x;
while (cin >> x && x != 0) {
    a[cnt] = x;
    cnt++;
}
for (int i = cnt - 1; i >= 0; i--) {
    cout << a[i] << " ";
}
```

## 知识扩展

- **数学关联**：逆序遍历 = 下标递减，等价于数学上的"反向索引"
- **编程思维**：`while (cin >> x)` 是"读到不能读为止"的惯用写法
- **延伸思考**：如果要求"间隔一个输出一个"（如取第 1、3、5 个），下标要怎么写？
