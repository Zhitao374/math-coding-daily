## 题目

给两个正整数 a 和 b，求它们的最小公倍数（LCM）。

输入：a b（两个正整数）
输出：一个整数（最小公倍数）

数据范围：1 ≤ a, b ≤ 10^9。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 12 18 | 36 |

## 思考方式

### 朴素想法

从 max(a, b) 开始，一个个往上试：
第一个能同时整除 a 和 b 的数，就是最小公倍数。

12 和 18：试 18、19、20……直到 36 能同时整除。

但 a、b 大时这个方法太慢——
最小公倍数可能到 a × b（10^18），根本试不完。

### 发现规律

观察到：**a × b = gcd(a, b) × lcm(a, b)**

验证：12 × 18 = 216
gcd(12, 18) = 6
lcm(12, 18) = 216 ÷ 6 = 36 ✓

**两个数的乘积，等于最大公约数乘最小公倍数。**

### 关键突破

所以求 lcm，只需两步：

```
第 1 步：求 gcd(a, b)  （用上一题的辗转相除）
第 2 步：lcm = a * b / gcd
```

**关键细节**：`a * b` 可能溢出——a、b 到 10^9 时，a * b 到 10^18。
要用 `long long` 或者先除后乘：

```
lcm = a / gcd * b;    // 先除，避免溢出
```

先除再乘，结果一样，但安全。

## 代码

```cpp
long long a, b;
cin >> a >> b;

// 求 gcd（辗转相除）
long long x = a, y = b;
while (y != 0) {
    long long r = x % y;
    x = y;
    y = r;
}
// x 就是 gcd

cout << a / x * b;        // 先除后乘，避免溢出
```

## 知识扩展

- **数学关联**：a × b = gcd(a, b) × lcm(a, b)——数论里的基本恒等式
- **编程思维**：溢出是竞赛编程的常见坑，先除后乘是标准技巧
- **延伸思考**：如果要求"三个数的最小公倍数"，怎么用 gcd 递推？
