## 题目

大象要喝 20 升水。一个圆柱形水桶，底面半径 r 厘米，高 h 厘米。大象至少要喝多少桶水？

输入：r h（水桶底面半径（厘米）、高（厘米））
输出：一个整数（最少桶数）

数据范围：1 ≤ r, h ≤ 100。π 取 3.14，1 升 = 1000 立方厘米。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 10 10 | 7 |

## 思考方式

### 朴素想法

先算水桶体积，再算要几桶。

水桶体积 = π × r² × h = 3.14 × 10² × 10 = 3140 立方厘米
20 升 = 20000 立方厘米
20000 ÷ 3140 = 6.37

大象要喝 6.37 桶？但水桶是整桶的，
不可能喝 0.37 桶——**要向上取整**，答案 7 桶。

### 发现规律

先算水桶的体积（圆柱体积公式 `V = πr²h`）：

代入 r = 10、h = 10：
V = 3.14 × 10² × 10 = 3140 立方厘米。

20 升 = 20000 立方厘米。
20000 ÷ 3140 = 6.37。

大象要喝 6.37 桶？但水桶是整桶的，
不可能喝 0.37 桶——**要向上取整**，答案 7 桶。

### 关键突破

向上取整的技巧：`向上取整(a ÷ b) = (a + b - 1) ÷ b`

用 20000 和 3140 代入：
(20000 + 3140 - 1) ÷ 3140 = 23139 ÷ 3140 = 7。

正好得到 7。

## 代码

```cpp
double r, h;
cin >> r >> h;
int v = 3.14 * r * r * h;      // 单桶体积（立方厘米）
int need = 20000;              // 需要的水量
int ans = (need + v - 1) / v;  // 向上取整
cout << ans;
```
