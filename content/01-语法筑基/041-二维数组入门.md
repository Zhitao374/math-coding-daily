## 题目

给 n 个学生，每人有三门课成绩。求每人的总分。

输入：第一行一个整数 n；接下来 n 行，每行三个整数
输出：n 个整数，每人的总分

数据范围：1 ≤ n ≤ 1000，每门成绩 0-150。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 3<br>90 95 88<br>76 82 79<br>100 100 100 | 273<br>237<br>300 |

## 图形

```
学生1:  [90] [95] [88]
学生2:  [76] [82] [79]
学生3:  [100][100][100]
        ↑ 一门课
```

## 思考方式

### 朴素想法

一维数组能存一行数据——
用 `a[i]` 表示第 i 个学生的**一个**成绩。

但每个学生有**三门课**，一个 `a[i]` 装不下。
要么开三个一维数组，要么换一种容器。

### 发现规律

一维数组的下标是**一个数**——`a[0]`、`a[1]`、`a[2]`。
如果下标改成**两个数**呢？

用 `a[i][j]` 表示"第 i 个学生的第 j 门课"：
- `a[0][0]` = 学生 1 的第 1 门课
- `a[0][1]` = 学生 1 的第 2 门课
- `a[1][0]` = 学生 2 的第 1 门课

这就是**二维数组**——数组的数组。

### 关键突破

二维数组和"表格"一一对应：

- **一维** = 一排
- **二维** = 一张表

读入和遍历都需要**双重循环**：

```
for (int i = 0; i < n; i++)          // 每一行
    for (int j = 0; j < 3; j++)      // 每行里三列
        cin >> a[i][j];
```

外层 `i` 控制"行"，内层 `j` 控制"列"。

## 代码

```cpp
int n;
cin >> n;
int a[1005][3];
for (int i = 0; i < n; i++)
    for (int j = 0; j < 3; j++)
        cin >> a[i][j];

for (int i = 0; i < n; i++) {
    int sum = 0;
    for (int j = 0; j < 3; j++) sum += a[i][j];
    cout << sum << "\n";
}
```

## 知识扩展

- **数学关联**：二维数组 = 矩阵 / 表格，`a[i][j]` 是"第 i 行第 j 列"
- **编程思维**：从一维到二维是"维度升级"——相同的结构，多一个下标
- **延伸思考**：如果要算"每门课的平均分"（对列求和），循环要怎么写？
