## 题目

给定 n 和 k，把 1 到 n 中能被 k 整除的数分为 A 类，其余分为 B 类。求 A、B 两类的平均值。

输入：n k（两个整数）
输出：两个实数（A 类平均值、B 类平均值，各保留一位小数）

数据范围：1 ≤ n ≤ 10000，1 ≤ k ≤ 100。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 100 16 | 56.0 50.1 |

## 对比

| 一次循环分两类 | 两次循环分别算 |
|---|---|
| 边判边加，走一遍 | 先算 A 类，再算 B 类 |
| 各自需要 sum 和 cnt | 代码重复两段 |
| 代码紧凑 | 逻辑清晰 |

## 思考方式

### 朴素想法

"能被 k 整除"就是 `i % k == 0`。

要算两类平均值，每类都需要：
平均值 = `总和 ÷ 个数`

所以循环里要维护 4 个变量：

- A 类的总和 `sumA`、A 类的个数 `cntA`
- B 类的总和 `sumB`、B 类的个数 `cntB`

### 发现规律

走一遍循环，边走边分：

```
for i 从 1 到 n：
    如果 i 能被 k 整除：加到 A 类的 sum，A 类计数 +1
    否则：加到 B 类的 sum，B 类计数 +1
```

关键：**"平均值"需要两个东西——总和 和 个数。**
每次循环，根据条件判断走哪条分支。

### 关键突破

代码结构就是"循环 + 分支 + 累加"：

```
for (int i = 1; i <= n; i++) {
    if (i % k == 0) { sumA += i; cntA++; }
    else            { sumB += i; cntB++; }
}
cout << sumA / cntA << " " << sumB / cntB;
```

注意：`cntA` 和 `cntB` 是 int，
但求和后的除法要得到实数——所以 sum 要用 double，
或者除的时候强制转换。

## 代码

```cpp
int n, k;
cin >> n >> k;
double sumA = 0, sumB = 0;
int cntA = 0, cntB = 0;
for (int i = 1; i <= n; i++) {
    if (i % k == 0) { sumA += i; cntA++; }
    else            { sumB += i; cntB++; }
}
cout << fixed << setprecision(1);
cout << sumA / cntA << " " << sumB / cntB;
```

## 知识扩展

- **数学关联**：整除判断 `i % k == 0` 是数论里的基本操作
- **编程思维**：一个循环处理多个统计目标，是"边扫描边分类"的典型写法
- **延伸思考**：如果 k 换成"i 的数字和能被 3 整除"，代码要怎么改？
