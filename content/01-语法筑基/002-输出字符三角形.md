## 题目

输入一个字符，用它输出一个 3 行的三角形。

输入：一个字符 c
输出：3 行三角形，每行前的空格用空格字符填充

## 图形

```
  A
 AAA
AAAAA
```

## 思考方式

### 朴素想法

直接一行一行输出：
第一行 2 个空格加 1 个 c，
第二行 1 个空格加 3 个 c，
第三行 0 个空格加 5 个 c。

但如果三角形有 100 行呢？
手写 100 行太累，也会写错。

### 发现规律

看每一行的规律：

| 行号 i | 空格数 | 字符数 |
|---|---|---|
| 1 | 2 | 1 |
| 2 | 1 | 3 |
| 3 | 0 | 5 |

空格数 = 3 - i，字符数 = 2 × i - 1。

### 关键突破

把公式翻译成循环的边界条件：

```
第 i 行的空格数 = 3 - i
  → 循环 j 从 1 到 (3 - i)

第 i 行的字符数 = 2i - 1
  → 循环 j 从 1 到 (2i - 1)
```

想画多高的三角形，只需要把 3 换一个数字。

## 代码

```cpp
char c;
cin >> c;              // 输入任意字符
int n = 3;             // 三角形行数，改这里就能改大小
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= n - i; j++) cout << " ";
    for (int j = 1; j <= 2 * i - 1; j++) cout << c;
    cout << "\n";
}
```

## 知识扩展

- **数学关联**：每一行的字符数构成等差数列 1, 3, 5, 7……
- **编程思维**：把"手工重复"变成"循环生成"，这是编程的核心价值
- **延伸思考**：如果把 n 从 3 改成 5，输出会变成什么样？试着手算一下。
