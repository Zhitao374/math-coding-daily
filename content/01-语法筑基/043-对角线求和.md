## 题目

给一个 n × n 的方阵，求主对角线和副对角线上所有数的和。

- 主对角线：从左上到右下（`a[0][0]`、`a[1][1]`、……）
- 副对角线：从右上到左下（`a[0][n-1]`、`a[1][n-2]`、……）

**注意**：中心元素只算一次。

输入：第一行一个整数 n；接下来 n 行，每行 n 个整数
输出：一个整数（两条对角线的和，去掉重复计算的中心元素）

数据范围：1 ≤ n ≤ 100，每个数 0-1000。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 3<br>1 2 3<br>4 5 6<br>7 8 9 | 25 |

（主对角线：1+5+9 = 15；副对角线：3+5+7 = 15；5 算了两次，减掉一次 → 15+15-5 = 25）

## 图形

```
    [1]  2   3
     4  [5]  6
     7   8  [9]
  主对角线：1、5、9

     1   2  [3]
     4  [5]  6
    [7]  8   9
  副对角线：3、5、7

  中心 5 被两条对角线共用。
```

## 思考方式

### 朴素想法

两条对角线分别遍历——但要判断每个元素是不是在对角线上。

笨办法：两层循环遍历所有元素，用 if 判断 `a[i][j]` 是否在两条对角线上。

能跑，但比较绕，也容易出错。

### 发现规律

看对角线的**位置规律**：

**主对角线**：`a[0][0]`、`a[1][1]`、`a[2][2]`……
→ **行列下标相等**：`a[i][i]`

**副对角线**：`a[0][2]`、`a[1][1]`、`a[2][0]`……
→ **行列下标之和 = n-1**：`a[i][n-1-i]`

有了公式，根本不用遍历所有元素——
**一条对角线遍历一次就够了**。

### 关键突破

两条对角线分别用一个循环：

```
// 主对角线
for (int i = 0; i < n; i++) sum += a[i][i];

// 副对角线
for (int i = 0; i < n; i++) sum += a[i][n - 1 - i];
```

但注意——**中心元素被算了两次**（当 n 为奇数时）。

**减掉一次中心元素**：

```
if (n % 2 == 1) sum -= a[n/2][n/2];
```

## 代码

```cpp
int n;
cin >> n;
int a[105][105];
for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
        cin >> a[i][j];

int sum = 0;
for (int i = 0; i < n; i++) {
    sum += a[i][i];               // 主对角线
    sum += a[i][n - 1 - i];       // 副对角线
}
if (n % 2 == 1) sum -= a[n/2][n/2];   // 中心元素算了两遍

cout << sum;
```

## 知识扩展

- **数学关联**：n 阶方阵有两条对角线，中心元素在 n 为奇数时重合
- **编程思维**：先找"位置规律"（下标关系），再写循环——比暴力遍历简洁得多
- **延伸思考**：如果要算"上三角"或"下三角"的和（i < j 或 i > j 的部分），代码要怎么写？
