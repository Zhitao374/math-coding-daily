## 题目

给一个正整数 n，求 n!（n 的阶乘）。

$$n! = 1 × 2 × 3 × … × n$$

输入：一个整数 n
输出：一个整数（n 的阶乘）

数据范围：1 ≤ n ≤ 12（保证结果不超过 int 范围）。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 5 | 120 |

## 思考方式

### 朴素想法

5! = 1 × 2 × 3 × 4 × 5 = 120。

手算也行，但 n = 12 时就很难算准——12! 是个 9 位数。

计算机擅长做"重复的乘法"。

### 发现规律

阶乘是典型的**递推**：
每一项都是前一项乘一个数。

```
1! = 1
2! = 1! × 2 = 2
3! = 2! × 3 = 6
4! = 3! × 4 = 24
5! = 4! × 5 = 120
```

和"累加"一样，只是把"加"换成"乘"。

### 关键突破

代码结构和"求和"几乎一样——把 `sum += i` 换成 `res *= i`：

```
int res = 1;                // 注意：乘法单位是 1，不是 0
for (int i = 1; i <= n; i++) {
    res *= i;               // 累乘
}
cout << res;
```

**关键细节**：初始化必须是 **1**，不能是 0——
0 乘任何数都是 0，结果会永远错。

## 代码

```cpp
int n;
cin >> n;
int res = 1;                 // 累乘器：从 1 开始
for (int i = 1; i <= n; i++) {
    res *= i;
}
cout << res;
```

## 知识扩展

- **数学关联**：阶乘 n! 表示 n 个不同物品的全排列数
- **编程思维**：累乘和累加是同一套结构，只是初始值和运算符不同
- **延伸思考**：如果要算 1! + 2! + 3! + … + n!（阶乘之和），程序需要怎么改？
