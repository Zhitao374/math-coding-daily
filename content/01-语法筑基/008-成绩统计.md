## 题目

作业、小测、期末三项成绩，分别占最终成绩的 20%、30%、50%。给三项成绩，求最终成绩。

输入：a b c（作业成绩、小测成绩、期末成绩）
输出：一个整数（最终成绩，向下取整）

数据范围：0 ≤ a, b, c ≤ 100。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 100 80 90 | 89 |

## 思考方式

### 朴素想法

直接求三个数的平均：
(100 + 80 + 90) ÷ 3 = 90

但这是**算术平均**，和题意不符——
因为三项占比不同，期末考试的权重更大。

### 发现规律

每一项要乘它自己的权重，再相加。

作业 100 × 20% = 20
小测 80 × 30% = 24
期末 90 × 50% = 45

20 + 24 + 45 = 89

这就是**加权平均**——每一项的"分量"不一样。

### 关键突破

把百分数写成小数，直接乘：

最终成绩 = 作业 × 0.2 + 小测 × 0.3 + 期末 × 0.5

在 C++ 里，整数乘小数会得到小数，
赋值给 int 时自动向下取整，正好符合题目要求。

## 代码

```cpp
int a, b, c;
cin >> a >> b >> c;
int total = a * 0.2 + b * 0.3 + c * 0.5;
cout << total;
```

## 知识扩展

- **数学关联**：算术平均 vs 加权平均
- **编程思维**：浮点数与整数混合运算时，自动提升为浮点，赋值给整数时截断
- **延伸思考**：如果四项成绩占比分别是 10%、20%、30%、40%，程序要怎么改？
