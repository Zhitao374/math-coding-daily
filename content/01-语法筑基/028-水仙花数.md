## 题目

"水仙花数"是指一个三位数，它的各位数字的立方和等于它本身。

比如：

$$153 = 1³ + 5³ + 3³$$

求 100 到 999 之间所有的水仙花数。

输入：无
输出：若干个整数，每个一行（升序）

## 输入输出样例

| 输入 | 输出 |
|---|---|
| （无） | 153<br>370<br>371<br>407 |

## 思考方式

### 朴素想法

从 100 遍历到 999，对每个数检查是不是水仙花数。

关键问题——**怎么把三位数的百位、十位、个位拆出来？**

试几个例子：
- 153 的百位是 1，十位是 5，个位是 3

怎么从 153 得到 1、5、3？

### 发现规律

用"取余 + 整除"两步拆位：

```
153 % 10 = 3           ← 个位
153 / 10 = 15          ← 去掉个位
15 % 10 = 1            ← 等等，这不是十位
```

嗯，上面算错了。正确步骤是：

```
153 / 1 % 10   = 3     ← 个位
153 / 10 % 10  = 5     ← 十位
153 / 100 % 10 = 1     ← 百位
```

或者更直观的写法：

```
百位 = n / 100
十位 = n / 10 % 10
个位 = n % 10
```

拆出各位后，算立方和判断即可。

### 关键突破

用**循环遍历** 100 到 999，每个数**拆位、算立方和、判断**：

```
for (int n = 100; n <= 999; n++) {
    int a = n / 100;         // 百位
    int b = n / 10 % 10;     // 十位
    int c = n % 10;          // 个位
    if (a*a*a + b*b*b + c*c*c == n)
        cout << n << "\n";
}
```

"循环 + 条件"是这类"找符合某种性质的所有数"的标准结构。

## 代码

```cpp
for (int n = 100; n <= 999; n++) {
    int a = n / 100;             // 百位
    int b = n / 10 % 10;         // 十位
    int c = n % 10;              // 个位
    if (a*a*a + b*b*b + c*c*c == n)
        cout << n << "\n";
}
```

## 知识扩展

- **数学关联**："水仙花数"又叫阿姆斯特朗数，是"自幂数"在三位的特例
- **编程思维**：数位分解用"整除 + 取余"，是处理"每一位"的通用技巧
- **延伸思考**：如果是四位数，要找"各位数字四次方和等于本身"的数（四叶玫瑰数），代码要改哪几处？
