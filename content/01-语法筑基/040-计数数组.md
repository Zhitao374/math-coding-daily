## 题目

给 n 个整数（范围 1 到 1000），从小到大**去重**后输出。

输入：第一行一个整数 n；第二行 n 个整数
输出：第一行一个整数（去重后的个数）；第二行去重后的整数（升序）

数据范围：1 ≤ n ≤ 100，每个数在 1 到 1000 之间。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 10<br>20 40 32 67 40 20 89 300 400 15 | 8<br>15 20 32 40 67 89 300 400 |

## 思考方式

### 朴素想法

最直接的做法：

- 读入所有数，排序
- 遍历一遍，把和前一个不同的输出

或者：

- 对每个数，检查它在前面是否出现过
- 没出现过就输出

**两种都需要"额外的判断"**——要么排序，要么双重循环检查。

### 发现规律

换个角度想——**这道题的数字范围只有 1 到 1000**。

能不能开一个 1000 大小的数组，**用"下标"当数字，用"值"当"出现过没"**？

```
int cnt[1005] = {0};       // 全部初始化为 0
cnt[20] = 1;               // 数字 20 出现过
cnt[40] = 1;               // 数字 40 出现过
cnt[15] = 1;               // 数字 15 出现过
```

读入每个数时，把 `cnt[x]` 标成 1。**重复的数字会覆盖成同一个 1**——天然去重。

### 关键突破

输出时**从下标 1 遍历到 1000**：

```
for (int i = 1; i <= 1000; i++) {
    if (cnt[i] == 1) {
        cout << i << " ";
    }
}
```

**因为下标天然有序**，输出就是从大到小排序的——连排序都省了。

**这就是"桶排序"的思想**：数字本身就是下标，自然排序。

## 代码

```cpp
int n;
cin >> n;
int cnt[1005] = {0};       // 全部初始化为 0

for (int i = 0; i < n; i++) {
    int x;
    cin >> x;
    cnt[x] = 1;            // 标记 x 出现过（重复也只会是 1）
}

// 先数个数
int total = 0;
for (int i = 1; i <= 1000; i++) {
    if (cnt[i]) total++;
}
cout << total << "\n";

// 再依次输出
for (int i = 1; i <= 1000; i++) {
    if (cnt[i]) cout << i << " ";
}
```

## 知识扩展

- **数学关联**：计数数组 = 集合的"特征函数"，`cnt[x] = 1` 表示 x 在集合里
- **编程思维**：桶排序 / 计数排序——用"下标有序"来替代"排序算法"
- **延伸思考**：如果数字范围是 1 到 10^9，还能用计数数组吗？为什么？
