## 题目

给 n 个数，找出其中最小的那个。

输入：第一行一个整数 n；第二行 n 个整数
输出：一个整数（最小值）

数据范围：1 ≤ n ≤ 100，所有数不超过 1000。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 5<br>3 7 2 9 5 | 2 |

## 思考方式

### 朴素想法

5 个数，一眼就看出最小的是 2。但如果 100 个数呢？
一个个扫过去也能找到，只是容易看漏。

计算机能替我们"挨个检查"——它会老老实实走完所有数，
不会分心，也不会看漏。

### 发现规律

流程其实很简单——准备一个"目前最小值"，走过每个数时都比一下。

```
目前最小值 = 第一个数
看第 2 个数：如果比目前最小值小，更新
看第 3 个数：如果比目前最小值小，更新
...
看完所有数，目前最小值就是答案
```

关键：**用一个变量记住"目前最小"，边走边更新。**

### 关键突破

把上面的流程翻译成循环：

```
int minVal = a[1];              // 先假设第一个数最小
for (int i = 2; i <= n; i++) {
    if (a[i] < minVal)          // 发现更小的
        minVal = a[i];          // 更新记录
}
cout << minVal;
```

这就像守门员——**只有比当前记录更小的数，才能"进门"**。

## 代码

```cpp
int n;
cin >> n;
int a[105];
for (int i = 1; i <= n; i++) cin >> a[i];

int minVal = a[1];               // 先假设第一个数最小
for (int i = 2; i <= n; i++) {
    if (a[i] < minVal) minVal = a[i];
}
cout << minVal;
```

## 知识扩展

- **数学关联**：最小值是集合的性质之一，找最小值的次数是 n-1 次比较
- **编程思维**："先假设一个，再逐一更新"是处理极值问题的通用思路
- **延伸思考**：如果要同时找最小值和最大值，循环里需要写几个 if？
