## 题目

计算 1 + 2 + 3 + … + n 的和。

输入：n（一个整数）
输出：一个整数（1 到 n 的和）

数据范围：1 ≤ n ≤ 10000。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 100 | 5050 |

## 对比

| 循环累加 | 数学公式 |
|---|---|
| 从 1 加到 n | (1 + n) × n ÷ 2 |
| O(n) | O(1) |
| 适合"边算边用" | 只求最终和 |

## 思考方式

### 朴素想法

从 1 开始，一个一个加：

```
sum = 0
sum = 0 + 1 = 1
sum = 1 + 2 = 3
sum = 3 + 3 = 6
...
```

这就是"累加"——和之前"求平均年龄"是同一个模式。

### 发现规律

每次加的数都是"上一个数 + 1"，
这就是循环变量 `i` 的天然行为：

```
for (int i = 1; i <= n; i++) {
    sum += i;
}
```

**循环变量 i 从 1 走到 n，每一次加到 sum**。

### 关键突破

其实这道题有**数学公式**——等差数列求和：

$$S = (1 + n) × n ÷ 2$$

100 个数代入：(1 + 100) × 100 ÷ 2 = 5050。

**公式一步算出，循环要跑 100 次。**

但循环不是"低效"，而是**通用**——不是所有求和都有公式。
当"没有公式"时，循环就是唯一的解法。

## 代码

```cpp
int n;
cin >> n;
int sum = 0;
for (int i = 1; i <= n; i++) {
    sum += i;                // 累加
}
cout << sum;
```

## 知识扩展

- **数学关联**：等差数列求和公式 S = (首项 + 末项) × 项数 ÷ 2
- **编程思维**：有公式时用公式，没公式时才用循环——选择取决于问题
- **延伸思考**：如果要求 1² + 2² + 3² + … + n² 呢？有没有类似公式？
