## 题目

给三条边的长度，判断它们能组成什么三角形。

输出规则：
- 不能构成三角形：Not a triangle
- 等边三角形：Equilateral
- 等腰三角形：Isosceles
- 普通三角形：Scalene
- 如果是直角三角形，在前面加上 Right

输入：a b c（三条边的长度）
输出：三角形类型（可能多个标签，用空格分隔）

数据范围：1 ≤ a, b, c ≤ 10000。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 3 4 5 | Right Scalene |
| 2 2 2 | Equilateral |
| 3 3 4 | Isosceles |
| 1 2 5 | Not a triangle |

## 思考方式

### 朴素想法

看到题很复杂——三角形有好几类，
还要判断直角三角形。

最直接的想法：用多个 if-else 层层判断。
但如果 a、b、c 顺序不固定，
判断"哪条边是斜边"就变得很麻烦。

### 发现规律

三个关键观察：

**观察 1**：判断能否构成三角形，用"两边之和大于第三边"。
但为了不重复判断，可以**先排序**，让 a ≤ b ≤ c，
然后只需验证 `a + b > c` 一条规则。

**观察 2**：判断直角三角形，用勾股定理 `a² + b² = c²`。
排序后 c 一定是最大边，只有一种判断。

**观察 3**：等边三角形一定是等腰三角形——
但题目要求先判断更特殊的，所以要按"等边 → 等腰 → 普通"顺序检查。

### 关键突破

把思路翻译成代码：

```
第 1 步：把 a, b, c 排序，让 a ≤ b ≤ c
第 2 步：a + b > c 才构成三角形，否则输出 Not a triangle
第 3 步：检查是不是直角三角形，是就先输出 Right
第 4 步：检查等边 / 等腰 / 普通
```

注意输出顺序：**先特殊后普通**——样例里是 `Right Scalene`，
所以直角标签放最前面。

## 代码

```cpp
int a, b, c;
cin >> a >> b >> c;
if (a > b) swap(a, b);
if (a > c) swap(a, c);
if (b > c) swap(b, c);
if (a + b <= c) {
    cout << "Not a triangle";
} else {
    if (a * a + b * b == c * c) cout << "Right ";
    if (a == b && b == c) cout << "Equilateral";
    else if (a == b || b == c) cout << "Isosceles";
    else cout << "Scalene";
}
```

## 知识扩展

- **数学关联**：勾股定理——直角三角形两直角边的平方和等于斜边的平方
- **编程思维**：排序后分类是一种常用的简化技巧，避免重复讨论
- **延伸思考**：如果边长是实数（带小数），`a * a + b * b == c * c` 还能直接比较吗？
