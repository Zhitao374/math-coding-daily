## 题目

输入一个字符，用它输出一个 5 行的菱形。

输入：一个字符 c
输出：5 行菱形，每行前的空格用空格字符填充

## 图形

```
  A
 AAA
AAAAA
 AAA
  A
```

## 思考方式

### 朴素想法

直接一行一行手写输出：
第 1 行 2 个空格 + 1 个 c
第 2 行 1 个空格 + 3 个 c
第 3 行 0 个空格 + 5 个 c
第 4 行 1 个空格 + 3 个 c
第 5 行 2 个空格 + 1 个 c

5 行还写得动，
但如果要输出 51 行的菱形呢？

### 发现规律

菱形是**上下对称**的：

- 第 1 行和第 5 行一样（1 个 c）
- 第 2 行和第 4 行一样（3 个 c）
- 第 3 行单独是中间行

规律：
- 空格数 = |3 - 行号|
- 字符数 = 5 - 2 × 空格数

### 关键突破

既然上下对称，就可以**分开处理**：

上半部分（含中间行）：行号从 1 到 3
下半部分：行号从 2 倒着到 1

```
上半部分：i = 1, 2, 3
下半部分：i = 2, 1
```

这两个循环用的是同一套规则。

## 代码

```cpp
char c;
cin >> c;
int n = 3;                                 // 上半部分行数
for (int i = 1; i <= n; i++) {             // 上半部分
    for (int j = 1; j <= n - i; j++) cout << " ";
    for (int j = 1; j <= 2 * i - 1; j++) cout << c;
    cout << "\n";
}
for (int i = n - 1; i >= 1; i--) {         // 下半部分
    for (int j = 1; j <= n - i; j++) cout << " ";
    for (int j = 1; j <= 2 * i - 1; j++) cout << c;
    cout << "\n";
}
```

## 知识扩展

- **数学关联**：对称图形可以用"镜像"生成——只需写一半
- **编程思维**：把重复的结构封装，是对称性的直接翻译
- **延伸思考**：如果要输出"空心菱形"（只有边框），代码需要怎么改？
