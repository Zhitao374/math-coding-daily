## 题目

从家到学校需要走 s 米，速度 v 米/分钟。学校 8:00 上课，需要提前 10 分钟到。最晚几点几分从家出发？

输入：s v（路程（米）、速度（米/分钟））
输出：最晚出发时刻（HH:MM 格式）

数据范围：1 ≤ s, v ≤ 10^4。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 100 100 | 07:48 |

## 思考方式

### 朴素想法

先算走路需要多少分钟：
时间 = 路程 ÷ 速度 = s ÷ v。

再往前推：8:00 出发太晚，
要提前 10 分钟，还要加上走路时间。

看起来是一道"简单加减法"。

### 发现规律

一切都要换算成同一个单位——分钟。

```
8:00 = 480 分钟
最晚出发时刻 = 480 - 10 - 走路分钟数
```

但可能超过 24:00 或小于 0:00，
需要处理"跨天"的情况。

还有一个容易忽略的点：
走路时间不是整数怎么办？
100 米 ÷ 3 米每分钟 = 33.33 分钟，
不足一分钟也要算一分钟，要向上取整。

### 关键突破

时间计算的核心是"统一单位"：
- 把 8:00 换成 480 分钟
- 加减都在分钟层面进行
- 最后再换回"时:分"格式

向上取整公式：
```
分钟数 = (s + v - 1) / v
```

## 代码

```cpp
int s, v;
cin >> s >> v;
int walk = (s + v - 1) / v;      // 向上取整
int total = 480 - 10 - walk;     // 换算成分钟
if (total < 0) total += 1440;    // 跨天处理
printf("%02d:%02d", total / 60, total % 60);
```

## 知识扩展

- **数学关联**：时间的六十进制与十进制换算
- **编程思维**：单位统一是处理"多单位问题"的关键思路
- **延伸思考**：如果还要算"晚上 10 点前必须睡觉"，程序需要怎么改？
