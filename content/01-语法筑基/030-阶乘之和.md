## 题目

给定正整数 n，求：

$$S = 1! + 2! + 3! + … + n!$$

输入：一个整数 n
输出：一个整数（S 的值）

数据范围：1 ≤ n ≤ 12（保证 S 不超过 int 范围）。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 3 | 9 |

（1! + 2! + 3! = 1 + 2 + 6 = 9）

## 思考方式

### 朴素想法

每一步都从头算阶乘，然后加起来：

```
1! = 1
2! = 1 × 2 = 2
3! = 1 × 2 × 3 = 6
```

加起来 = 1 + 2 + 6 = 9。

但每次算阶乘都要从 1 乘到 n——
算 5! 时重复算 1×2×3×4，其实前面已经算过 4! 了。

**这是浪费。**

### 发现规律

观察相邻两项的阶乘：

```
2! = 1! × 2
3! = 2! × 3
4! = 3! × 4
```

**n! 就是 (n-1)! 再乘以 n。**
不需要从头乘——只需要一个变量记住"上一项的阶乘"。

### 关键突破

用一个变量 `fact` 保存当前阶乘，
每一步只乘 n，不再重复乘 1 到 n-1：

```
int fact = 1;                // 1!
int sum = 0;
for (int i = 1; i <= n; i++) {
    fact *= i;               // 递推：i! = (i-1)! × i
    sum += fact;             // 累加到总和
}
cout << sum;
```

**一次循环同时做两件事**——算阶乘、累加和。

## 代码

```cpp
int n;
cin >> n;
int fact = 1;                // 累乘器：保存当前阶乘
int sum = 0;                 // 累加器：保存总和
for (int i = 1; i <= n; i++) {
    fact *= i;               // i! = (i-1)! × i
    sum += fact;             // 把 i! 加到总和
}
cout << sum;
```

## 知识扩展

- **数学关联**：阶乘的递推关系 `n! = (n-1)! × n` 是"动态规划"最简单的例子
- **编程思维**：用变量保存"上一项"避免重复计算，是"用空间换时间"的雏形
- **延伸思考**：如果直接暴力算每一项阶乘（每项都从头乘），程序会多算多少次乘法？
