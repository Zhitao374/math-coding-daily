## 题目

一个整数正着读是 123，倒着读是 321。给你一个数，输出它倒过来的结果。

输入：s（一个整数，不超过 100 位）
输出：倒过来读的结果

数据范围：位数 ≤ 100。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 123 | 321 |
| 100 | 001 |

## 思考方式

### 朴素想法

直接把数字当"一串字符"处理：
读入 123，看作字符 '1'、'2'、'3'，
倒着输出就是 '3'、'2'、'1'。

但数字和字符串是两种不同的东西——
数字能计算，但取不出"每一位"。

### 发现规律

字符串天然支持"反转"——
只要知道长度，从最后一位往前依次输出就行。

关键观察：数字适合计算，字符串适合处理"每一位"。
同一个数据，用不同的方式表示，
能做的事完全不一样。

### 关键突破

读入时用字符串，反转时按字符处理：

```
读入字符串 s = "123"
从 i = s.length() - 1 开始
倒着输出每一位
```

注意：反转后前面的 0 会被保留。
这不是"数字"，而是"字符序列"。

## 代码

```cpp
string s;
cin >> s;
for (int i = s.length() - 1; i >= 0; i--)
    cout << s[i];
```

## 知识扩展

- **数学关联**：位值原理——同一个数字在不同位置代表不同的值
- **编程思维**：字符串和数字是两种不同的数据表示，选择哪种取决于问题
- **延伸思考**：如果输入是 001，反转后应该输出 100 还是 001？
