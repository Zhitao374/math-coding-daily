## 题目

给体重 m（千克）和身高 h（米），计算 BMI 并判断体型。

$$BMI = m ÷ (h × h)$$

| BMI 范围 | 体型 |
|---|---|
| BMI < 18.5 | Underweight |
| 18.5 ≤ BMI < 24 | Normal |
| BMI ≥ 24 | Overweight |

输入：m h（体重（千克）、身高（米））
输出：体型判断（如果 BMI ≥ 24，先输出 BMI 保留 6 位有效数字，再输出 Overweight）

数据范围：1 ≤ m ≤ 1000，0.5 ≤ h ≤ 3。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 70 1.72 | Normal |
| 100 1.6 | 39.0625 Overweight |

## 思考方式

### 朴素想法

先算 BMI，再用 if-else 判断区间：

```
如果 BMI < 18.5：输出 Underweight
否则如果 BMI < 24：输出 Normal
否则：输出 Overweight
```

看起来是道简单的分支题。

### 发现规律

仔细看题目——**BMI ≥ 24 时，要先输出 BMI 数值，再输出 Overweight**。

这不是普通的分支题，输出有**两种格式**：
- BMI < 24：只输出一个单词
- BMI ≥ 24：先输出一个数，再输出一个单词

需要先算好 BMI，再根据区间决定输出什么。

还有精度问题：
- BMI 要"保留 6 位有效数字"
- 样例 `39.0625` 就是 6 位有效数字

C++ 的 `cout << setprecision(6)` 默认是 6 位**有效数字**，
正好符合要求。

### 关键突破

处理"保留 6 位有效数字"用：

```
cout << setprecision(6) << bmi;
```

注意：如果 BMI 是 100 这样的大数，6 位有效数字会显示 `100.000`。
而如果 BMI 是 5.5，会显示 `5.50000`。
有效数字和"小数位数"不一样——要小心理解。

## 代码

```cpp
double m, h;
cin >> m >> h;
double bmi = m / (h * h);
if (bmi < 18.5) {
    cout << "Underweight";
} else if (bmi < 24) {
    cout << "Normal";
} else {
    cout << setprecision(6) << bmi << " " << "Overweight";
}
```

## 知识扩展

- **数学关联**：BMI 公式——体重 ÷ 身高²，是人体健康评估的常用指标
- **编程思维**：`setprecision(n)` 控制有效数字位数，注意和"小数位数"的区别
- **延伸思考**：如果要求"保留 2 位小数"而不是"6 位有效数字"，代码需要怎么改？
