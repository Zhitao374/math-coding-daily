## 题目

给一个年份 y，判断它是不是闰年。

输入：y（年份，整数）
输出：1（闰年）或 0（平年）

数据范围：1582 ≤ y ≤ 9999。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 2000 | 1 |
| 1900 | 0 |

## 思考方式

### 朴素想法

闰年不就是能被 4 整除的年份吗？
1904 ÷ 4 = 476，能整除，是闰年。
1900 ÷ 4 = 475，也能整除，应该也是闰年吧？

但查日历会发现——**1900 年不是闰年**。

"能被 4 整除"这个条件不完整。

### 发现规律

完整的闰年规则有两层：

- 普通年份：能被 4 整除
- 世纪年份（整百年）：必须能被 400 整除

用一句话说：**能被 4 整除，但不能被 100 整除，或者能被 400 整除**。

验证一下：
- 2000：能被 400 整除 ✓ 闰年
- 1900：能被 100 整除但不能被 400 整除 ✗ 平年
- 2024：能被 4 整除但不能被 100 整除 ✓ 闰年

### 关键突破

把规则翻译成逻辑表达式：

```
闰年 = (y % 4 == 0 且 y % 100 != 0) 或 (y % 400 == 0)
```

C++ 里：
- `&&` 表示"且"
- `||` 表示"或"
- `%` 表示取余

注意括号的优先级：`&&` 比 `||` 高，所以要先用括号组合条件。

## 代码

```cpp
int y;
cin >> y;
if ((y % 4 == 0 && y % 100 != 0) || y % 400 == 0)
    cout << 1;
else
    cout << 0;
```

## 知识扩展

- **数学关联**：闰年的天文依据——地球公转周期约 365.2422 天，每四年补一天，但每百年少补一天
- **编程思维**：复杂条件用括号分组，让优先级一目了然
- **延伸思考**：如果再加一条"每 3200 年不闰"的规则，代码怎么改？
