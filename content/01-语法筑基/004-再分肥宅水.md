## 题目

一瓶 t 毫升的饮料平均分给 n 个人。每人分到多少毫升？需要几个杯子？

输入：t n（饮料总量（毫升，实数）、人数（整数））
输出：第一行每人分到的毫升数（保留三位小数）、第二行杯子总数

数据范围：0 < t ≤ 10000，1 ≤ n ≤ 1000。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 500.0 3 | 166.667<br>3 |

## 思考方式

### 朴素想法

"平均分"就是做除法：
500 ÷ 3 = 166.666……，保留三位小数。

这看起来是一道"纯除法题"。

### 发现规律

再读一遍题，其实有两个不同的问题：
第一个问题：每人多少毫升？→ 需要小数除法
第二个问题：要几个杯子？→ 需要整数个数

一个问题里出现了两种"除法"：
- 精确除法（得到小数）
- 整数除法（得到个数）

### 关键突破

在 C++ 里，两种除法由数据类型决定：

```
double t = 500.0;
double avg = t / n;        // 精确除法，得到小数
int cups = n;              // 每人一个杯子

cout << fixed << setprecision(3) << avg;
```

同一道题里，选对数据类型比写对算式更重要。

## 代码

```cpp
double t;
int n;
cin >> t >> n;
cout << fixed << setprecision(3) << t / n << "\n";
cout << n;
```

## 知识扩展

- **数学关联**：除法有两种含义——"平均分"和"求倍数"
- **编程思维**：数据类型决定运算结果，浮点数用于精确值，整数用于计数
- **延伸思考**：如果杯子是 250 毫升的，n = 3 时需要几个杯子？
