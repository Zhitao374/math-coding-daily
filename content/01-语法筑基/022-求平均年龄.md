## 题目

班上 n 个学生，每个人报一个年龄。求全班的平均年龄。

输入：第一行一个整数 n；第二行 n 个实数（每个学生的年龄）
输出：一个实数（平均年龄，保留两位小数）

数据范围：1 ≤ n ≤ 100，每个年龄不超过 150。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 3<br>10 11 12 | 11.00 |

## 思考方式

### 朴素想法

平均年龄 = 所有年龄加起来 ÷ 人数。

3 个人手算容易：
(10 + 11 + 12) ÷ 3 = 33 ÷ 3 = 11.00

但 100 个人呢？一个个加，容易算错。

### 发现规律

计算机的强项就是**累加**。

用一个变量 `sum` 从 0 开始，
每读到一个年龄，就把它加进去：

```
sum = 0
读第 1 个：sum = 0 + 10 = 10
读第 2 个：sum = 10 + 11 = 21
读第 3 个：sum = 21 + 12 = 33
```

加完后，`sum` 就是总和，再除以 n 就是平均。

### 关键突破

"累加"是循环最经典的用法。代码极短：

```
double sum = 0;           // 总和，用 double 因为年龄可能是小数
for (int i = 0; i < n; i++) {
    double x;
    cin >> x;
    sum += x;             // 累加
}
cout << fixed << setprecision(2) << sum / n;
```

注意 `sum` 用 `double` —— 如果年龄带小数（比如 10.5），
用 int 就会丢掉精度。

## 代码

```cpp
int n;
cin >> n;
double sum = 0;                  // 累加器：从 0 开始
for (int i = 0; i < n; i++) {
    double x;
    cin >> x;
    sum += x;                    // 累加
}
cout << fixed << setprecision(2) << sum / n;
```

## 知识扩展

- **数学关联**：算术平均数——总和除以个数
- **编程思维**：累加器（accumulator）是一个从初始值出发、逐步更新的变量
- **延伸思考**：如果要算"去掉最高分和最低分后的平均分"，程序需要怎么改？
