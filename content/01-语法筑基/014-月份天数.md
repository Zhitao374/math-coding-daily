## 题目

翻开日历，看 2024 年 2 月有几天。给定年份和月份，输出这个月的天数。

输入：y m（年份、月份）
输出：一个整数（这个月的天数）

数据范围：1582 ≤ y ≤ 9999，1 ≤ m ≤ 12。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 2024 2 | 29 |
| 1900 2 | 28 |

## 思考方式

### 朴素想法

用 if-else 判断月份：

```
如果 m = 1、3、5、7、8、10、12，输出 31
如果 m = 4、6、9、11，输出 30
如果 m = 2，看年份是不是闰年，输出 28 或 29
```

能跑，但 12 个 if 太啰嗦。

### 发现规律

12 个月的天数是**固定的一张表**：

```
1月  2月  3月  4月  5月  6月
31   28   31   30   31   30

7月  8月  9月  10月 11月 12月
31   31   30   31   30   31
```

与其用 12 个 if，不如直接把这个表**存进数组**。

### 关键突破

用一个数组存 12 个月的天数，直接用月份作为下标访问：

```
days[1] = 31
days[2] = 28   （平年）
days[3] = 31
...
```

2 月需要特殊处理：如果是闰年，答案改成 29。
闰年规则上一题（011）刚学过。

## 代码

```cpp
int y, m;
cin >> y >> m;
int days[] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
bool leap = (y % 4 == 0 && y % 100 != 0) || y % 400 == 0;
if (m == 2 && leap)
    cout << 29;
else
    cout << days[m];
```

## 知识扩展

- **数学关联**：月份天数的分布源于古罗马历法，2 月的"不公平"来自历史原因
- **编程思维**：数组代替多分支——用数据存储代替代码逻辑
- **延伸思考**：如果要算"从年初到这个月一共过了多少天"，怎么用同一张表算出来？
