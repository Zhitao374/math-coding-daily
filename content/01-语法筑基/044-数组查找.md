## 题目

给 n 个整数，再给一个目标数 x。找出 x 在数组中的**第一个位置**（从 1 开始编号）。

如果 x 不在数组里，输出 -1。

输入：第一行一个整数 n；第二行 n 个整数；第三行一个整数 x
输出：一个整数（位置，或 -1）

数据范围：1 ≤ n ≤ 1000，每个数 -10000 到 10000。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 5<br>3 7 2 9 5<br>9 | 4 |
| 5<br>3 7 2 9 5<br>8 | -1 |

## 追踪

| i | a[i] | 与 x=9 比较 |
|---|---|---|
| 0 | 3 | 不等 |
| 1 | 7 | 不等 |
| 2 | 2 | 不等 |
| 3 | 9 | 相等 → 记录位置 4 |
| 4 | 5 | 不再看（已经找到） |

## 思考方式

### 朴素想法

从前往后逐个比较——遇到等于 x 的就记录位置。

**一次循环，一次判断**。看起来很直接。

但有两个细节容易错：
- 是"第一个位置"，不是"任意一个"
- 找不到要输出 -1，不能忘

### 发现规律

关键：**找到第一个就该停止**。

如果不停止，后面的相同值会覆盖掉前面的位置——
那就不是"第一个"了。

用 `break` 提前退出：

```
for (int i = 0; i < n; i++) {
    if (a[i] == x) {
        pos = i + 1;
        break;          // 找到就停
    }
}
```

**"找到即停"**是这道题的核心。

### 关键突破

还需要一个"是否找到"的标志——
`pos` 初始化为 -1，找到就更新：

```
int pos = -1;             // 假设找不到
for (int i = 0; i < n; i++) {
    if (a[i] == x) {
        pos = i + 1;
        break;
    }
}
cout << pos;
```

**技巧**：初始值设成"找不到时的值"（-1），
如果循环走完 `pos` 还是 -1，说明真的没找到。

## 代码

```cpp
int n;
cin >> n;
int a[1005];
for (int i = 0; i < n; i++) cin >> a[i];

int x;
cin >> x;

int pos = -1;              // 假设找不到
for (int i = 0; i < n; i++) {
    if (a[i] == x) {
        pos = i + 1;
        break;             // 找到即停
    }
}
cout << pos;
```

## 知识扩展

- **数学关联**：查找 = 判断"x 是否属于集合"，位置 = 它在序列中的索引
- **编程思维**：`break` 提前退出 + 用"哨兵值"表示"没找到"——两个经典技巧
- **延伸思考**：如果要找"最后一个位置"，把循环改成从后往前遍历，能解决吗？
