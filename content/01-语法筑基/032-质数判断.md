## 题目

判断一个数 n 是不是质数。

质数：只能被 1 和它本身整除的数（大于 1）。

输入：n（一个整数）
输出：1（是质数）或 0（不是质数）

数据范围：1 ≤ n ≤ 10000。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 7 | 1 |
| 12 | 0 |

## 思考方式

### 朴素想法

"质数只能被 1 和它本身整除"——
意思是：从 2 到 n-1，**都除不尽**。

从 2 试到 n-1，看有没有一个数能整除 n：

```
如果找到整除的 → 不是质数
全都试完没找到 → 是质数
```

### 发现规律

试到 n-1 太慢——n = 10000 时要试 9998 次。

但注意：**如果 n 有因数 a，那么 n = a × b，a 和 b 中必有一个 ≤ √n**。

比如 12 = 3 × 4，3 ≤ √12 ≈ 3.5，4 > √12。
所以只需检查到 √n 就够了。

### 关键突破

从 n-1 次试除降到 √n 次：

```
for (int i = 2; i * i <= n; i++) {
    if (n % i == 0) return false;
}
return true;
```

**`i * i <= n` 就是 `i <= √n`**——用整数乘法避免浮点误差。

这是"因数成对出现"这个数学观察的直接翻译。

## 代码

```cpp
int n;
cin >> n;
bool isPrime = (n >= 2);
for (int i = 2; i * i <= n; i++) {
    if (n % i == 0) {
        isPrime = false;
        break;                // 一旦找到因数，直接退出
    }
}
cout << (isPrime ? 1 : 0);
```

## 知识扩展

- **数学关联**：因数是成对出现的——如果 a 是因数，n÷a 也是因数
- **编程思维**：`break` 提前退出循环，避免不必要的计算
- **延伸思考**：如果要判断 1 到 100 万之间**所有**数是不是质数，一个一个判断要多久？
