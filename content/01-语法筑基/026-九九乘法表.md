## 题目

输出下三角形式的九九乘法表（9 行）。

## 图形

```
1*1=1
1*2=2 2*2=4
1*3=3 2*3=6 3*3=9
1*4=4 2*4=8 3*4=12 4*4=16
1*5=5 2*5=10 3*5=15 4*5=20 5*5=25
...
```

## 思考方式

### 朴素想法

直接手写 45 个算式？太累了。

而且一旦格式要求变了——比如把下三角改成上三角，
或者把 9 行改成 12 行——手写的全部要重来。

需要找到能"自动重复"的方法。

### 发现规律

观察每一行的算式数量：

| 行号 | 算式个数 |
|---|---|
| 1 | 1 |
| 2 | 2 |
| 3 | 3 |
| ... | ... |
| 9 | 9 |

**第 i 行恰好有 i 个算式**——每一行都比上一行多一个。

再看每个算式的形式：`j * i = j*i`。
其中 i 是行号，j 从 1 递增到 i。

### 关键突破

用一个"双层循环"自动生成：

```
外层循环 i 从 1 到 9：控制行
    内层循环 j 从 1 到 i：控制每行的算式
        输出 "j*i=结果"
    换行
```

**外层决定"做几行"，内层决定"每行做几次"。**
这就是双重循环——**循环里再放一个循环**。

## 代码

```cpp
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        cout << j << "*" << i << "=" << j * i << " ";
    }
    cout << "\n";
}
```

## 知识扩展

- **数学关联**：乘法表是"直角坐标"的雏形——行号 × 列号决定位置
- **编程思维**：双重循环——外层控制"大步骤"，内层控制"小步骤"，是处理二维问题的标准结构
- **延伸思考**：如果要输出**上三角**乘法表（每行递减），内外层循环要改哪几处？
