## 题目

给两个正整数 a 和 b，求它们的最大公约数（GCD）。

输入：a b（两个正整数）
输出：一个整数（最大公约数）

数据范围：1 ≤ a, b ≤ 10^9。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 12 18 | 6 |

## 思考方式

### 朴素想法

从 1 试到 min(a, b)，找能同时整除 a 和 b 的最大数。

```
for (int i = min(a, b); i >= 1; i--) {
    if (a % i == 0 && b % i == 0) { cout << i; break; }
}
```

正确但慢——a、b 到 10^9 时要试几亿次。

### 发现规律

**欧几里得观察**：gcd(a, b) = gcd(b, a % b)

用 12 和 18 验证：

```
gcd(12, 18)
= gcd(18, 12 % 18) = gcd(18, 12)
= gcd(12, 18 % 12) = gcd(12, 6)
= gcd(6, 12 % 6) = gcd(6, 0)
= 6
```

**每一步数字都在变小**，很快就到 0。到 0 时，另一个数就是答案。

### 关键突破

把观察翻译成循环：

```
while (b != 0) {
    int r = a % b;    // 求余数
    a = b;            // 旧的 b 变新的 a
    b = r;            // 余数变新的 b
}
// 循环结束时，a 就是答案
```

**关键**：两个变量在循环里"接力"，一个交棒给另一个。
这就是"辗转相除"——直到余数为 0。

## 代码

```cpp
int a, b;
cin >> a >> b;
while (b != 0) {
    int r = a % b;           // 余数
    a = b;                   // 接力：b 变 a
    b = r;                   // 接力：r 变 b
}
cout << a;
```

## 知识扩展

- **数学关联**：欧几里得算法——2300 年前《几何原本》里就有的算法
- **编程思维**：两个变量"接力"是算法里的常见模式（后面学 DP 也会用到）
- **延伸思考**：为什么 gcd(a, b) = gcd(b, a % b)？试着用因数关系证明
