## 题目

给一个 n × n 的方阵，输出三个数：

1. 所有元素的和
2. 主对角线元素的和
3. 每行最大值的总和

输入：第一行一个整数 n；接下来 n 行，每行 n 个整数
输出：三个整数，用空格分隔

数据范围：1 ≤ n ≤ 100，每个数 0-1000。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 3<br>1 2 3<br>4 5 6<br>7 8 9 | 45 15 18 |

（总和：1+...+9 = 45；主对角线：1+5+9 = 15；每行最大：3+6+9 = 18）

## 思考方式

### 朴素想法

三个任务，可以写三段独立的循环。

每一段都遍历二维数组，但**关注点不同**：
- 第一段：全部相加
- 第二段：只加 `a[i][i]`
- 第三段：每行单独找最大值

### 发现规律

三段任务，都是"二维数组 + 遍历 + 处理"：

| 任务 | 遍历范围 | 处理 |
|---|---|---|
| 求和 | 所有元素 | 累加 |
| 对角线 | `a[i][i]` | 累加 |
| 每行最大 | 每行所有元素 | 求极值 |

**共同结构**：双重循环
**差异**：内层判断条件不同

### 关键突破

**"每行最大值"的循环结构不一样**——
不是"遍历所有元素"，而是"外层行，内层找该行最大"：

```
for (int i = 0; i < n; i++) {
    int maxRow = a[i][0];              // 先假设行首最大
    for (int j = 1; j < n; j++) {
        if (a[i][j] > maxRow) maxRow = a[i][j];
    }
    sumMax += maxRow;
}
```

注意：**`maxRow` 每一行都要重新初始化**——
放在内层循环外、外层循环内。

## 代码

```cpp
int n;
cin >> n;
int a[105][105];
for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
        cin >> a[i][j];

int sumAll = 0, sumDiag = 0, sumMax = 0;

for (int i = 0; i < n; i++) {
    int maxRow = a[i][0];
    for (int j = 0; j < n; j++) {
        sumAll += a[i][j];             // 任务 1
        if (a[i][j] > maxRow) maxRow = a[i][j];
    }
    sumMax += maxRow;                  // 任务 3
    sumDiag += a[i][i];                // 任务 2
}

cout << sumAll << " " << sumDiag << " " << sumMax;
```

## 知识扩展

- **数学关联**：二维数组 = 矩阵，遍历 + 求和 / 求极值是基本操作
- **编程思维**：一次循环完成多个任务——只要没有顺序依赖，可以合并
- **延伸思考**：如果要算"每列最大值"（对列求极值），循环结构需要怎么调整？
