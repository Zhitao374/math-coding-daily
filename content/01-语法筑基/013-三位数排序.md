## 题目

三个小朋友站成一排，按身高从矮到高排好。给你三个数，输出排序后的结果。

输入：a b c（三个整数）
输出：排序后的三个整数，用一个空格分隔

数据范围：0 ≤ a, b, c ≤ 100。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 3 1 2 | 1 2 3 |

## 思考方式

### 朴素想法

三个数排序，最直接的方法是**分情况讨论**。
a b c 三个数的顺序一共 6 种可能：

```
a≤b≤c, a≤c≤b, b≤a≤c, b≤c≤a, c≤a≤b, c≤b≤a
```

写 6 个 if……太啰嗦了。

### 发现规律

想象三个位置，让最小的数"冒"到最左边。

- 先比较 a 和 b：如果 a 比 b 大，就交换它们
- 再比较 a 和 c：如果 a 比 c 大，就交换
- 最后比较 b 和 c：如果 b 比 c 大，就交换

三对比较做完，三个数就按顺序排好了。
这就是**冒泡排序**的思想。

### 关键突破

用交换函数 `swap(a, b)` 把三次比较写成三行：

- 第 1 步：让 a 是 a、b 里较小的
- 第 2 步：让 a 是 a、c 里较小的（此时 a 已经是三个数里最小的）
- 第 3 步：让 b 是 b、c 里较小的

这样 a、b、c 就是从小到大排的。

## 代码

```cpp
int a, b, c;
cin >> a >> b >> c;
if (a > b) swap(a, b);   // 保证 a ≤ b
if (a > c) swap(a, c);   // 保证 a 是最小的
if (b > c) swap(b, c);   // 保证 b ≤ c
cout << a << " " << b << " " << c;
```

## 知识扩展

- **数学关联**：三个数的全排列共 6 种，通过比较可以唯一确定顺序
- **编程思维**：`swap()` 是 C++ 内置函数，交换两个变量的值
- **延伸思考**：如果扩展到 5 个数排序，用"冒泡"的思路要比较几次？
