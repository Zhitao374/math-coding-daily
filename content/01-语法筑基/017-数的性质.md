## 题目

给一个整数 n，依次输出 4 个判断结果（1 或 0）：

- 性质 1：n 是偶数，且 n 大于 4
- 性质 2：n 是偶数，或 n 大于 4
- 性质 3：n 是偶数，且 n 不大于 4
- 性质 4：n 不是偶数，且 n 不大于 4

输入：n（一个整数）
输出：4 个 0 或 1，用空格分隔

数据范围：0 ≤ n ≤ 1000。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 5 | 0 1 0 0 |
| 6 | 1 1 0 0 |

## 思考方式

### 朴素想法

看到题目有 4 个判断，最直接的方法是——把每个判断拆开，用 if 判断。

性质 1 需要"且"：n 偶数 **and** n > 4
性质 2 需要"或"：n 偶数 **or** n > 4
性质 3、4 类似，都是两个条件的组合。

写 4 个 if-else 就好。看起来不难。

### 发现规律

但是性质 1 和性质 3 是一对"互补"的：
- 性质 1：偶数 **且** 大于 4
- 性质 3：偶数 **且** 不大于 4

同一个"偶数"条件，后面接的是相反的判断。
把 n 分成"大于 4"和"不大于 4"两类，正好互补。

再看性质 2 和性质 4：
- 性质 2：偶数 **或** 大于 4
- 性质 4：非偶数 **且** 不大于 4

这两个看起来不像一对，但它们**逻辑上是互补的**：
"或"的否定是"都非"——即"非偶数且不大于 4"。

### 关键突破

把四个性质翻译成 C++ 逻辑表达式：

```
性质 1 = 偶数(n) && (n > 4)
性质 2 = 偶数(n) || (n > 4)
性质 3 = 偶数(n) && (n <= 4)
性质 4 = !偶数(n) && (n <= 4)
```

其中"偶数(n)" = `n % 2 == 0`。

注意 `&&` 的优先级高于 `||`，必要时加括号。

## 代码

```cpp
int n;
cin >> n;
bool even = (n % 2 == 0);
bool big  = (n > 4);
cout << (even && big)  << " ";
cout << (even || big)  << " ";
cout << (even && !big) << " ";
cout << (!even && !big);
```

## 知识扩展

- **数学关联**：逻辑运算——"且"、"或"、"非"的真值表
- **编程思维**：用布尔变量（`bool`）存中间结果，比直接写复杂表达式更清晰
- **延伸思考**：性质 2 和性质 4 的结果一定互补吗？举几个 n 验证一下。
