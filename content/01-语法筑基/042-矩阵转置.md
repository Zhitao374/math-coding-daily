## 题目

给一个 n × m 的矩阵，输出它的转置（m × n）。

转置：原来的第 i 行第 j 列，变成新矩阵的第 j 行第 i 列。

输入：第一行 n m；接下来 n 行，每行 m 个整数
输出：m 行，每行 n 个整数

数据范围：1 ≤ n, m ≤ 100，每个整数 0-1000。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 2 3<br>1 2 3<br>4 5 6 | 1 4<br>2 5<br>3 6 |

## 图形

```
原矩阵 (2×3):       转置后 (3×2):
  [1] [2] [3]         [1] [4]
  [4] [5] [6]         [2] [5]
                      [3] [6]
```

## 思考方式

### 朴素想法

直接按行读、按列写——

但问题来了：读入时是 `a[i][j]`，
输出时要变成 `b[j][i]`。

**行和列的位置交换了。**

### 发现规律

观察 `a` 和 `b` 的关系：
- `a[0][0] = 1` → `b[0][0] = 1`
- `a[0][1] = 2` → `b[1][0] = 2`
- `a[0][2] = 3` → `b[2][0] = 3`
- `a[1][0] = 4` → `b[0][1] = 4`

**规律**：`b[j][i] = a[i][j]`

下标只是换了个位置——**行列对调**。

### 关键突破

用**双重循环**遍历原矩阵，每次把 `a[i][j]` 写到 `b[j][i]`：

```
for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++)
        b[j][i] = a[i][j];
```

注意：**`n × m` 的矩阵转置后是 `m × n`**——
`b` 的第一维大小是 `m`，第二维是 `n`。

## 代码

```cpp
int n, m;
cin >> n >> m;
int a[105][105], b[105][105];
for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++)
        cin >> a[i][j];

// 转置：行列下标对调
for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++)
        b[j][i] = a[i][j];

// 输出
for (int i = 0; i < m; i++) {
    for (int j = 0; j < n; j++)
        cout << b[i][j] << " ";
    cout << "\n";
}
```

## 知识扩展

- **数学关联**：矩阵转置——把第 i 行变成第 j 列，是一个基本操作
- **编程思维**：下标对调 `a[i][j] ↔ a[j][i]`，是二维数组的典型操作
- **延伸思考**：如果不开新数组 `b`，直接在原矩阵上原地转置，能做到吗？（提示：n = m 才行）
