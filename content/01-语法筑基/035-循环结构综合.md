## 题目

综合复习循环结构的应用。

**任务清单**：

1. 求 1 到 100 之间所有偶数的和
2. 求 1 到 n 之间所有 3 的倍数的个数
3. 判断 n 是不是"完数"（等于其所有真因数之和）

输入：n（一个整数）
输出：三个答案，用空格分隔

数据范围：1 ≤ n ≤ 10000。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 28 | 2550 9 1 |

（28 是真因数 1+2+4+7+14 = 28，是完数）

## 思考方式

### 朴素想法

三道题看着像三个不同的题，但**本质是同一个套路**：
"从 1 到某个数走一遍，符合条件的就处理"。

- 第 1 题：遍历 1 到 100，遇到偶数就加
- 第 2 题：遍历 1 到 n，遇到 3 的倍数就计数
- 第 3 题：遍历 1 到 n-1，遇到因数就加

### 发现规律

三道题可以**用三段独立的循环分别算**：

```
第一段：1 到 100，偶数累加
第二段：1 到 n，3 的倍数计数
第三段：1 到 n-1，找因数求和，判断是否等于 n
```

**每一段都是"循环 + 分支 + 累加/计数"**——
这正好是循环结构的三个标准用法。

### 关键突破

关键是把"看起来不同"的问题，都翻译成**同一个模板**：

```
for (int i = 起点; i <= 终点; i++) {
    if (满足条件) {
        累加 / 计数 / 其他处理
    }
}
```

**掌握了这个模板，就能处理绝大多数"循环类"问题。**

## 代码

```cpp
int n;
cin >> n;

// 第 1 题：1 到 100 之间所有偶数的和
int sum1 = 0;
for (int i = 1; i <= 100; i++) {
    if (i % 2 == 0) sum1 += i;
}

// 第 2 题：1 到 n 之间所有 3 的倍数的个数
int cnt = 0;
for (int i = 1; i <= n; i++) {
    if (i % 3 == 0) cnt++;
}

// 第 3 题：判断 n 是不是完数
int sumDiv = 0;
for (int i = 1; i < n; i++) {
    if (n % i == 0) sumDiv += i;
}
int isPerfect = (sumDiv == n) ? 1 : 0;

cout << sum1 << " " << cnt << " " << isPerfect;
```

## 知识扩展

- **数学关联**：完数——古代数学家欧几里得研究过的特殊数，如 6、28、496
- **编程思维**：把"看似不同"的问题翻译成"同一个模板"，是算法思维的核心
- **延伸思考**：如果要算 1 到 10000 之间所有的完数，怎么用循环一次找出？
