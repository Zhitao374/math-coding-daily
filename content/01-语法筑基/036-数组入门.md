## 题目

给 n 个数，按原顺序输出它们。

输入：第一行一个整数 n；第二行 n 个整数
输出：n 个整数（原顺序，空格分隔）

数据范围：1 ≤ n ≤ 100，每个数不超过 1000。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 5<br>3 7 2 9 5 | 3 7 2 9 5 |

## 图形

```
索引:  [0]  [1]  [2]  [3]  [4]
值:     3    7    2    9    5
```

## 思考方式

### 朴素想法

如果不让用数组，会怎么做？

读一个数，输出一个数——循环 n 次：

```
for (int i = 1; i <= n; i++) {
    int x;
    cin >> x;
    cout << x << " ";
}
```

能过样例。但问题来了——**如果要求"逆序输出"呢？**
刚才读过的数已经忘了，没法倒着输出。

### 发现规律

需要一种"记下来"的容器——
**把 n 个数都存起来，下次想访问哪个就访问哪个**。

这就是数组：**一排编了号的储物柜**。

```
int a[105];
a[0] = 3;
a[1] = 7;
...
```

每个位置有编号（下标），可以从 0 开始逐个访问。

### 关键突破

数组的两个核心动作：

- **存**：`a[i] = x`（第 i 号柜子放 x）
- **取**：`x = a[i]`（从第 i 号柜子拿出 x）

用循环读入 n 个数：

```
for (int i = 0; i < n; i++) cin >> a[i];
```

用循环输出 n 个数：

```
for (int i = 0; i < n; i++) cout << a[i] << " ";
```

**有了数组，"先读后写"和"边读边写"都变得可能。**

## 代码

```cpp
int n;
cin >> n;
int a[105];
for (int i = 0; i < n; i++) cin >> a[i];   // 读入
for (int i = 0; i < n; i++) cout << a[i] << " ";   // 输出
```

## 知识扩展

- **数学关联**：数组 = 下标到值的映射，f(i) = a[i]
- **编程思维**：数组的价值在于"记住"，可以随机访问任意一个元素
- **延伸思考**：如果 n 是 100 万，用 `int a[105]` 会怎样？数组大小要怎么定？
