## 题目

给定 x，按下面的规则计算 y：

$$当 x < 0：y = -x$$

$$当 x = 0：y = 0$$

$$当 x > 0：y = x × 2 + 1$$

输入：x（一个整数）
输出：一个整数（y 的值）

数据范围：-1000 ≤ x ≤ 1000。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| -5 | 5 |
| 0 | 0 |
| 3 | 7 |

## 思考方式

### 朴素想法

数学里把这种"不同 x 对应不同公式"的函数叫**分段函数**。
比如 -x 是一段，x×2+1 是另一段。

翻译到代码，最直接的方法就是"分段判断"：
先判断 x 属于哪一段，再套用对应的公式。

### 发现规律

关键观察：**x < 0、x = 0、x > 0 三种情况，正好覆盖所有可能**。

- 每个 x 只会落在其中一段
- 三段互不重叠
- 检查顺序可以任意，但习惯上按从小到大

用 `if ... else if ... else` 结构最自然：

```
if (x < 0) 第一段公式
else if (x == 0) 第二段公式
else 第三段公式
```

### 关键突破

注意分段函数的**输出公式不同**，但可以用同一个变量 y 承接：

```
int y;
if (x < 0)      y = -x;
else if (x == 0) y = 0;
else             y = x * 2 + 1;
cout << y;
```

分段函数的代码结构几乎都是这个模板——
先判断区间，再套用公式。

## 代码

```cpp
int x;
cin >> x;
int y;
if (x < 0)       y = -x;
else if (x == 0) y = 0;
else             y = x * 2 + 1;
cout << y;
```

## 知识扩展

- **数学关联**：分段函数在现实里很常见——阶梯电价、个税税率都是分段计算
- **编程思维**：`if ... else if ... else` 是处理多分支的标准结构，检查顺序很重要
- **延伸思考**：如果再加一段"x > 100 时 y = x × 3"，应该插在哪个位置？
