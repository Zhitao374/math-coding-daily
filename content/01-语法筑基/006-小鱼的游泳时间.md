## 题目

小鱼从 a 时 b 分一直游到 c 时 d 分。它游了多久？

输入：a b c d（开始小时 开始分钟 结束小时 结束分钟）
输出：e f（游了多少小时 多少分钟）

数据范围：0 ≤ a, c ≤ 24，0 ≤ b, d ≤ 60，结束时间一定晚于开始时间。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 12 50 19 10 | 6 20 |

## 思考方式

### 朴素想法

直接用小时和分钟分别相减：
19:10 - 12:50，分钟 10 - 50 = -40，
负数说明需要向小时借位——直接减会算错。

再试一组：11:30 - 10:20，
分钟 30 - 20 = 10，小时 11 - 10 = 1，
结果是 1 小时 10 分。这次对了，但下一组又错。

问题在于：分钟部分有时要借位，有时不用。

### 发现规律

既然时间是六十进制的，
不如先换算成同一个单位——"从 0:00 开始过了多少分钟"。

12:50 = 12 × 60 + 50 = 770 分钟
19:10 = 19 × 60 + 10 = 1150 分钟

1150 - 770 = 380 分钟。

再换回"时:分"格式：
380 ÷ 60 = 6 小时……20 分钟。

### 关键突破

把时间统一成"总分钟数"，减法就不用借位。
最后再把结果换回时:分格式：

```
总分钟 = 结束 - 开始
小时 e = 总分钟 ÷ 60     （整数除法，向下取整）
分钟 f = 总分钟 % 60     （取余，结果 < 60）
```

## 代码

```cpp
int a, b, c, d;
cin >> a >> b >> c >> d;
int start = a * 60 + b;      // 开始时刻换算成分钟
int end   = c * 60 + d;      // 结束时刻换算成分钟
int total = end - start;     // 总分钟数
cout << total / 60 << " " << total % 60;
```

## 知识扩展

- **数学关联**：六十进制转十进制——1 小时 = 60 分钟
- **编程思维**：整数除法 `/` 和取余 `%` 是一对——前者给商，后者给余数
- **延伸思考**：如果比赛跨越了午夜（23:50 开始，00:20 结束），程序需要怎么改？
