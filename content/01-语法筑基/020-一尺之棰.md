## 题目

《庄子》里说："一尺之棰，日取其半，万世不竭。"

第一天有一根长度为 a 的木棍。从第二天开始，每天都要将木棍锯掉一半（每次除 2，向下取整）。

问：第几天的时候木棍长度会变为 1？

输入：a（木棍初始长度，整数）
输出：一个整数（木棍长度为 1 时是第几天）

数据范围：1 ≤ a ≤ 10^9。

## 输入输出样例

| 输入 | 输出 |
|---|---|
| 100 | 7 |

## 思考方式

### 朴素想法

木棍从 100 开始，每天砍一半：

| 天数 | 长度 |
|---|---|
| 第 1 天 | 100 |
| 第 2 天 | 50 |
| 第 3 天 | 25 |
| 第 4 天 | 12 |
| 第 5 天 | 6 |
| 第 6 天 | 3 |
| 第 7 天 | 1 |

答案是 7。

但 a 最大可以到 10^9，手算几百万行太累。
需要找到能"自动重复"的方法。

### 发现规律

把上面的过程用变量写出来：

```
天数 = 1
长度 = a
每次：长度 = 长度 / 2；天数 = 天数 + 1
直到：长度 = 1
```

这个过程有一个明显的特征——**重复做同一件事**。
重复做的事，用循环处理。

### 关键突破

把"每天砍一半"翻译成 while 循环：

```
int days = 1;
while (a > 1) {
    a = a / 2;      // 砍一半（整数除法自动向下取整）
    days++;
}
cout << days;
```

`while (a > 1)` 的意思是：只要长度还大于 1，就继续砍。
砍到长度为 1 时，循环结束，输出累计天数。

**整数除法自动向下取整**正好符合题目要求——不用额外处理。

## 代码

```cpp
int a;
cin >> a;
int days = 1;             // 第 1 天，长度就是 a
while (a > 1) {
    a = a / 2;            // 砍一半（向下取整）
    days++;
}
cout << days;
```

## 知识扩展

- **数学关联**：每次除以 2，重复 k 次后长度约等于 a / 2^k，这就是"对数级"过程
- **编程思维**：`while` 循环处理"重复到某条件为止"的问题，判断条件写在开头
- **延伸思考**：如果每天砍掉 1/3（即除 3 向下取整），程序需要改哪几行？
